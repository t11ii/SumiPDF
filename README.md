# SumiPDF

Windows x64 用の小さな PDF ビューアーです。複数の PDF をタブで開き、縦にスクロールして読み進められます。4色の蛍光ペン・下線と電子署名にも対応します。アプリ本体は Rust 製の単一 EXE です。

## 使い方

1. **[最新リリース](https://github.com/t11ii/SumiPDF/releases/latest)** から Windows x64 用の ZIP をダウンロードし、展開して `SumiPDF.exe` を起動します。対象は Windows 11 と Windows 10 バージョン 1709 以降の x64 環境です。
2. PDF をウィンドウにドロップするか、**Open…**（Ctrl + O）で選びます。複数選ぶと、それぞれが同じウィンドウのタブに開きます。エクスプローラーの「プログラムから開く」や `SumiPDF.exe "契約書.pdf" "別紙.pdf"` でも開けます。
3. ホイールまたはタッチパッドで縦にスクロールすると、ページの境目をまたいで読めます。タブをクリックして別の文書に移り、戻ると読んでいた位置・倍率・未保存の注釈が復元されます。各タブの × でその文書を閉じます。Ctrl + W は現在のタブを閉じます。

ウィンドウは濃いグレー、PDF のページは原本の色で表示します。メニューやツールチップは英語で表示します。`?`（Shift + /）を押すとショートカット一覧が開き、Esc で閉じられます。ウィンドウのシステムメニュー（Alt + Space）の **Keyboard shortcuts…** からも開けます。左右の矢印の間にあるページ番号をクリックすると、指定したページに移動します。注釈や署名を付けるときは対象ページを単独で表示し、ツールを閉じると連続表示に戻ります。

### 文書内を検索する

**Ctrl + F** で検索欄を開き、語句を入力します。一致箇所がページ上で色付きになり、**Enter** または **F3** で次へ、**Shift + Enter** または **Shift + F3** で前へ移動できます。**Esc** で検索欄と色付けが消えます。検索は署名済みの PDF でも使えます。スキャン画像だけのページを検索するには OCR 済みの PDF が必要です。縦書きや文字情報を復元できないフォントは検索対象外です。検索は 256 MiB までの PDF に対応し、一度に最大 5,000 件を表示します。

検索欄を開いている間は、解析済みの文字と位置を最大 8 MiB までメモリに保持します。語句を打ち直すと、保持したページは入力直後に再検索します。検索欄を閉じるかタブを切り替えると、このメモリを解放します。

### 蛍光ペンと下線を使う

1. **Highlight**（蛍光ペン）または **Underline**（下線）を押し、隣のドロップダウンで黄・赤・緑・青の色見本から選びます。最初の色は黄色です。選んだ色は、これから付ける注釈に適用されます。
2. 文字の先頭から末尾までドラッグします。複数行を選ぶと、行ごとに色や下線が付きます。スキャン画像や余白では、蛍光ペンは塗りたい範囲の対角を、下線は線を引きたい位置で横にドラッグします。**Undo** で直前の注釈を取り消せます。
3. **Save annotations…** でコピーを保存します。たとえば `契約書.pdf` の既定の保存名は `契約書-highlighted.pdf` です。保存後も、開いている文書で編集を続けられます。タイトルの `*` は未保存の変更を示します。

蛍光ペンは PDF 標準の Highlight 注釈、下線は Underline 注釈として保存します。文字位置を使う選択は横書きの一般的な欧文フォントや日本語の Identity-H フォントに対応します。縦書きフォントや特殊な文字配置では、画像と同じ操作で位置を指定できます。既に電子署名された PDF と暗号化 PDF は注釈の編集対象外です。

### 電子署名する

1. **Sign PDF…** を押し、署名位置の一覧で記入先を選びます。PDF に空の署名フィールドがあれば、ページ番号と名前が表示されます。印刷された署名欄やスキャンには **Draw signature box** を選び、欄を囲みます。青枠が署名の表示位置です。従来の不可視署名も選べます。
2. **Choose watermark** で標準模様、自分の PNG、または **Choose Acrobat watermark PDF…** から1ページの透かし PDF を選びます。次に署名するときも、選んだファイルを使います。**Create watermark…** で同梱のデザイナーが開きます。文字・書体・外枠・色・手描きを組み合わせ、**Save PNG** したら、署名画面の **Choose PNG…** で読み込みます。編集用の SVG も書き出せます。[透かしデザイナー](dist/watermarkDesigner.html)
3. 鍵アイコンの **Choose from the Windows certificate store** を押します。「現在のユーザー」と「ローカル コンピューター」の両方の「個人」ストアから、秘密鍵付きで有効な署名用証明書を探します。同じ氏名の候補があるときは、**View details** で発行者や有効期限を確認できます。自分の証明書を選ぶと画面下部に署名者名が表示されます。

   **PFX ファイルをお持ちの場合**は、鍵アイコンの右隣にある **Load certificate from PFX** を押します。`.pfx` または `.p12` を開き、パスワードを入力してください。ファイルに署名用証明書が複数あれば、使用する証明書を選べます。証明書のファイルと署名者を記憶するので、次回は **Sign and save…** に進めます。パスワードの入力も省略するには、最初の入力時に **Remember password on this PC** にチェックを入れます。パスワードは Windows の DPAPI で現在のユーザー向けに暗号化します。ファイルを交換した場合は再度選択してください。

4. **Sign and save…** を押して新しいファイルに保存します。証明書をここで初めて選ぶこともできます。証明書の氏名を左に、署名者情報と UTC 日時を右に配置し、透かしを背景に重ねます。画面で付けた注釈と署名の外観を含む PDF 全体が署名対象です。[参考にした Acrobat の署名表示](https://www.adobe.com/devnet-docs/acrobatetk/tools/DigSigDC/appearances.html)
5. 保存すると、署名済みのコピーが同じウィンドウの新しいタブで開きます。表示署名なら署名のあるページ、不可視署名なら保存前に表示していたページから確認できます。元の PDF には元のタブで戻れます。証明書や署名後の変更は、Acrobat Reader などの署名パネルで確認できます。信頼判定は受け手の証明書と検証環境によって決まります。

Windows ストアで選んだ証明書も、次回の署名時に呼び出せます。記憶した証明書と PFX の保存パスワードは、ウィンドウ左上のシステムメニュー（Alt + Space）の **Forget saved signing certificate** で消去できます。

初めて署名するときは、Acrobat DC 用に自分で設定した `%APPDATA%\Adobe\Acrobat\DC\Security\SignatureLogo.pdf` があれば、署名背景に使います。そのファイルがなければ SumiPDF の紙模様が初期値です。Acrobat 内蔵の Adobe PDF ロゴは Adobe の許諾を要するため、公開版には含めていません。[Acrobat の透かし設定](https://www.adobe.com/devnet-docs/acrobatetk/tools/DigSigDC/appearances.html) · [Adobe のロゴ利用条件](https://www.adobe.com/legal/permissions/trademarks.html)

### 別の人が署名した PDF に自分の署名を追加する

受け取った署名済み PDF を開き、**Sign PDF…** で自分の署名欄を選びます。通常の承認署名で位置に制限がなければ、空いている場所をドラッグして新しい署名欄も作れます。鍵アイコンで自分の証明書を選び、**Sign and save…** を押すと、元ファイルの末尾に自分の署名を追記したコピーを保存します。先に署名した人の署名はその時点の版を、自分の署名は先の署名を含む新しい版を保護します。

文書の証明設定や既存署名による欄のロックがある場合、SumiPDF では許可された既存の空欄を使います。変更が禁止された文書や対象欄がすべてロックされた文書には追加署名できません。先の署名者や証明書の信頼性は、必要に応じて署名前に Acrobat Reader などの署名パネルで確認してください。

### Claude Code・Codex から署名する

同じ Windows EXE をコマンドとして呼び出せます。`--inspect` で署名フィールドを列挙し、`--preview` でページや候補位置を PNG で確認し、`--sign` で署名済みコピーを作成します。印刷された欄やスキャンを扱うときは、エージェントがページ画像を読み、該当する矩形を指定します。使い方と PowerShell の実行例は ZIP にも同梱しています。[エージェント用ガイド](dist/signingGuide.md)

| ファイルをタブで開く（複数選択可） | Ctrl + O、ドロップ |
| 次・前のタブ | Ctrl + Tab / Ctrl + Shift + Tab |
| 現在のタブを閉じる | Ctrl + W |

| 下線の切り替え | U（終了は Esc でも可） |

## 軽量化と署名の仕様

- 閲覧には Windows 標準の PDF エンジンを使います。元ファイルをストリームで開き、画面に入るページを優先してバックグラウンドで描画します。画面の前後を1ページずつ先読みし、遠くのページ画像は解放します。連続表示で保持するページ画像は合計 48 MiB までです。タブを切り替えると、元のタブには閲覧位置・編集内容と開いていたファイルのストリームを保持し、ページ画像を解放します。プロセス全体の使用量は文書や表示サイズによって変わります。[Microsoft の PDF 描画 API](https://learn.microsoft.com/en-us/uwp/api/windows.data.pdf.pdfdocument?view=winrt-19041)
- 蛍光ペンか下線を使うときだけ、描画とは別のスレッドで PDF を解析し、表示ページの文字位置を求めます。ツールを閉じると、解析データを解放します。新しい注釈は原文の末尾に追記します。
- 署名用の全文解析は署名操作時に行います。表示に使ったファイルストリームから原文を取り出し、PDF の末尾に署名フィールドと署名辞書を追記します。元ファイルは閲覧中、読み取り共有で開きます。大きな PDF に署名する際は、元データ・解析結果・出力に応じて追加のメモリーを使います。
- Windows の暗号プロバイダーが秘密鍵で SHA-256 の分離 CMS 署名を作成します。PDF の署名形式は `adbe.pkcs7.detached` です。署名日時には PC の時計を使います。認定タイムスタンプや長期検証情報の付与は未対応です。[Microsoft の署名 API](https://learn.microsoft.com/en-us/windows/win32/api/wincrypt/nf-wincrypt-cryptsignmessage)
- 非暗号化の PDF に初回署名と追加署名ができます。追加署名時は既存の署名のバイト範囲と署名制限を検査します。暗号化 PDF、XFA、相互参照の修復を要する文書、解釈できない署名制限、署名後のサイズが 4 GiB 以上になる文書は対象外です。

## ビルドと検証

Windows x64 の Rust stable と Visual C++ Build Tools でビルドできます。

```powershell
cargo test --locked
$env:CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_RUSTFLAGS = "-C target-feature=+crt-static"
cargo build --release --locked --target x86_64-pc-windows-msvc
./tests/smoke.ps1 -Executable ./target/x86_64-pc-windows-msvc/release/SumiPDF.exe
```

Windows 用のテストは一時証明書を使う署名、改ざん検出、実際の PDF のレンダリングを扱います。PowerShell 7 のスモークテストは、複数の PDF を開き、タブ切り替え、未保存の注釈の復元、署名位置の選択を検査します。240 ページのテスト文書では、ページをまたぐスクロールや連続操作後の表示位置を調べ、操作時間とワーキングセットを記録します。CLI テストは現在のユーザーの個人ストアに一時証明書を作り、管理者権限のある Windows CI ではローカル コンピューターの個人ストアに追加署名用の一時証明書も作ります。PNG を指定した署名と原本のハッシュを検査した後、証明書とテスト鍵を削除します。同じ検査を実行する [Windows CI](.github/workflows/windows.yml) も付属しています。

macOS からは Rust の `x86_64-pc-windows-gnu` ターゲットと MinGW-w64 の GCC・windres を使います。

```sh
cargo build --release --locked --target x86_64-pc-windows-gnu
```

OpenSSL、NSS の certutil・pk12util、Poppler の pdfsig、pdftotext、pdftoppm が使える環境では、以下で外部検証テストも実行できます。保存した PDF を画像に描画し、蛍光ペンと下線の4色、複数行の選択範囲、回転・トリミング後の位置を確認します。追加署名では別々のテスト証明書を使い、2 件の署名の有効性、署名後に変更された版の検出、両方の署名欄の描画を検査します。

```sh
cargo test --locked -- --include-ignored
```
